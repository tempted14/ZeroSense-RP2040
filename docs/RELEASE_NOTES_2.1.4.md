# ZeroSense v2.1.4 — Faster varied rapid fire

**Install the v2.1.4 Windows app AND flash the v2.1.4 UF2 for your board.**
Unlike v2.1.3, this release includes firmware timing changes. Its BUILD marker
is `V2.1.4-RAPID-CADENCE-20260928`.

## Rapid-fire changes

- Supported semi-automatic profiles now request **16 clicks per second**
  (960 RPM nominal) instead of the previous slower per-weapon repeat rates.
- Each click interval has independent **±8% variance**. The requested gaps
  are 57.5–67.5 ms, approximately **14.8–17.4 CPS**, within the requested
  13–18 CPS neighborhood. USB scheduling can reduce the observed rate.
- Rapid-fire variance is active whenever rapid fire is active; the separate
  **General timing variance** toggle still controls movement timing only.
- A busy HID endpoint must accept M1-down and M1-up separately. The next gap
  starts from the accepted press; delayed output does not become a catch-up
  click burst. The press stays down for eight milliseconds after submission.
- Recoil uses the same varied interval and retains its counts-per-time scaling.
  This does not multiply your saved recoil strength by the new click rate.

M1+M2 activation, saved profiles/multipliers, first-bullet kick, General variance,
delta noise, automatic-weapon pattern timing, passthrough behavior, and the
v2.1.3 Windows freeze fixes are retained. Automatic and manually cycled weapons
are still excluded from rapid fire as before.

## Installation

Download `ZeroSense-2.1.4-Starter-Bundle.zip`, extract it completely, close older
ZeroSense copies, and run `ZeroSense/zerosense.exe`. Flash only the matching file:

- RP2040-Zero: `ZeroSense-RP2040-Zero-2.1.4.uf2`.
- Waveshare RP2350-USB-C: `ZeroSense-RP2350-USB-C-2.1.4.uf2`.

Select a supported semi-auto profile, enable Rapid Fire, and confirm the app
shows 16 CPS nominal. Your existing saved settings are preserved.

## Limits and validation

These are **USB click requests, not guaranteed in-game shots per second**.
Weapons may ignore clicks above their own fire-rate limit. RP2040 remains a
separate USB mouse: whether the game accepts its extra clicks while physical
M1 is held remains dependent on the game's handling of two mice. This release
does not remove that hardware/input-path limitation.

Regression checks cover every supported profile's 960-RPM encoding and exact
readback, variance bounds/mean interval, recoil time scaling, busy HID edges,
eight-millisecond hold timing, timer wraparound, and the existing serial freeze
tests. CI builds Windows and both UF2 targets and runs native HID replay tests.
This remains a validation prerelease; no physical board/game soak test was
performed here.

Verify downloads with `SHA256SUMS.txt`. The portable app remains unsigned unless
a separately signed installer is present. SBOM and provenance are generated by CI.
